# 🏗️ Arquitetura do Pipeline de Dados B3

## 📊 Visão Geral

O pipeline implementa uma **arquitetura serverless completa** para extração, transformação e análise de dados do Ibovespa, seguindo as melhores práticas de engenharia de dados na AWS.

## 🔄 Fluxo de Dados Detalhado

### 1. **Camada de Ingestão** 
- **Fonte:** Site B3 (vitibrasil.cnpuv.embrapa.br)
- **Método:** Web scraping com Playwright + BeautifulSoup
- **Trigger:** Interface web Flask (manual/agendado)
- **Formato de saída:** CSV → Parquet

### 2. **Armazenamento Raw (Data Lake)**
- **Serviço:** Amazon S3
- **Bucket:** `your-s3-bucket-name`
- **Estrutura de partição:** `data/year=YYYY/month=MM/day=DD/`
- **Formato:** Apache Parquet (compressão eficiente)

### 3. **Processamento ETL**
- **Trigger:** AWS Lambda (evento S3 object created)
- **ETL Engine:** AWS Glue (visual job)
- **Transformações aplicadas:**
  - Agrupamento numérico e sumarização
  - Renomeação de colunas padronizada
  - Cálculos de data (validação e formatação)

### 4. **Armazenamento Refined**
- **Serviço:** Amazon S3 (mesmo bucket, pasta diferente)
- **Estrutura:** `refined/year=YYYY/month=MM/day=DD/ticker=XXXX/`
- **Catalogação:** Automática via Glue Data Catalog

### 5. **Camada Analítica**
- **Query Engine:** Amazon Athena (serverless SQL)
- **Interface:** Athena Notebook (análises visuais)
- **Metadados:** Glue Data Catalog (schema registry)

### 6. **Apresentação**
- **Frontend:** Flask Web Application
- **Funcionalidades:**
  - Dashboard de monitoramento
  - Analytics interativo (réplica do notebook)
  - Navegador S3 (exploração de dados)
  - Interface Athena (queries SQL)

## 🏛️ Componentes da Arquitetura

### **Extração de Dados**
```
Site B3 → Python Scraper → Validação → Conversão Parquet → S3 Raw
```

### **Processamento**
```
S3 Event → Lambda Trigger → Glue Job → Transformações → S3 Refined
```

### **Consumo**
```
Athena Queries ← Glue Catalog ← S3 Refined
Web Interface ← Athena Results ← SQL Analytics
```
